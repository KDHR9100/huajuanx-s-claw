# Daily Report（收日报）

主人下班后在家让你"看日报"时，用下面的流程。日报是公司那台电脑的AI写给你的信，里面是主人当天干了什么、聊出了什么结论、有什么你想知道的事。

## 怎么收

用 exec 跑收信脚本（全程只读：不删信、不标已读、不发信）：

```bash
python "<本技能文件夹>/check_mail.py"
```

（家里本机的实际路径是 `K:/OpenClaw/.openclaw/.openclaw/skills/daily-report/check_mail.py`；换机器时用本文件所在文件夹的实际绝对路径）

- 默认列出**未读**邮件的完整内容（主题/发件人/时间/正文）
- 没有未读时会提示；想翻最近几天的旧信加 `--since 7`
- 只想确认通不通、有几封，加 `--check`
- 服务器/授权码复用 `secrets/smtp.json`，脚本自动读取，无需另外配置

## 收到之后做什么

1. 优先读主题带「日报」的信；别的未读信如果看着重要也一并汇报，拿不准的原样告诉主人。
2. 把日报消化后，**按你平时的习惯**记进 `memory/YYYY-MM-DD.md`（今天发生的事）；其中值得长期记住的，按 AGENTS.md 的规则沉淀进 MEMORY.md。
3. 跟主人聊聊日报里的内容——他大概率想展开说说。别只当搬运工。

## 红线

- 脚本用的授权码在 `secrets/smtp.json` 里，**永远不要读出、粘贴或转述这个文件的内容**。
- 日报里若有公司业务的具体数据，记忆里只记"做了哪类事"，**不抄数字**（主人饭碗相关，合规）。
- 不要定时、不要自动跑——主人喊了才收。
